# LifeOS — личный центр управления

LifeOS — одностраничное веб-приложение для личной продуктивности. Включает задачи, таймер Pomodoro, привычки, заметки и учёт бюджета.

## Запуск локально

Откройте `index.html` в современном браузере. Сборка, установка зависимостей и сервер не нужны.

## Публикация через GitHub Pages

1. Создайте на GitHub новый **Public** репозиторий, например `lifeos`.
2. Загрузите в корень репозитория файлы `index.html`, `README.md` и `.nojekyll`.
3. Откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Deploy from a branch**.
5. В качестве ветки выберите `main`, папку — `/(root)`, затем нажмите **Save**.
6. После публикации адрес сайта будет похож на `https://ВАШ-ЛОГИН.github.io/lifeos/`.

## Хранение данных

Приложение хранит пользовательские данные в локальном хранилище браузера на устройстве, где его используют. Данные не синхронизируются между устройствами автоматически. Используйте экспорт резервной копии, если эта функция доступна в приложении, и не вводите в сайт конфиденциальную информацию.
